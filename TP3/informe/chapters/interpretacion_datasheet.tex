\chapter{Interpretación de las especificaciones del fabricante}

Los pasos a seguir para la realización de esta actividad son:

Descargar de internet el \textit{datasheet} de los siguientes transistores:
    
\begin{itemize}
  \item BC548
  \item BC557
  \item 2N2222
  \item BU208
  \item MPS6514
  \item TIP36
\end{itemize}

Relevar los siguientes parámetros en cada uno y explicar el significado de los mismos:
    
Características eléctricas a 25$°C$
        \begin{itemize}
            \item $V_{(BR)CEO}$: Tensión de ruptura colector-emisor
            \item $I_{CEO}$: Corriente de fuga colector-emisor con base abierta
            \item $I_{CES}$: Corriente de fuga colector-emisor con base unida al emisor
            \item $I_C$: Corriente maxima de colector
            \item $I_{EBO}$: Corriente de fuga emisor-base
            \item $h_{FE}$: Ganancia de corriente (DC)
            \item $h_{fe}$: Ganancia de corriente (AC)
            \item $V_{BE}$: Tensión base-emisor
            \item $V_{CE(\text{sat})}$: Saturación colector-emisor
            \item $P_d$: Potencia disipada
        \end{itemize}

Características térmicas:

        \begin{itemize}
            \item $\theta_{jc}$: Resistencia térmica unión-colector
            \item $\theta_{ja}$: Resistencia térmica unión-ambiente
        \end{itemize}

Características de conmutación a 25$°C$:
        
        \begin{itemize}
            \item $t_{on}$: Tiempo de encendido (turn-on time)
        \end{itemize}
